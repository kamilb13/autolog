# AutoLog

Dziennik samochodu na Androida: wydatki, historia serwisu i terminy przeglądów.
Działa offline, bez zakładania konta.

[Pobierz APK](https://github.com/kamilb13/autolog/releases/latest/download/autolog.apk) · [Strona aplikacji](https://kamilb13.github.io/autolog/)

- Wiele pojazdów i osobna historia każdego auta.
- Tankowania, naprawy i pozostałe wydatki. Ręczne wpisy lub skan paragonu.
- Terminy przeglądów, ubezpieczenia i serwisu.
- Statystyki kosztów i raport PDF dla kupującego.
- Kopie danych do pliku JSON lub opcjonalnie na Google Drive.
